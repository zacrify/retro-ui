# Colors

All colors live in one place: the `@theme` block in `src/styles.css`.
Tailwind turns each `--color-*` variable into utility classes
(`bg-primary`, `text-primary-foreground`, `border-primary`, ...).
Components never hard-code a hex value; they pick a token by meaning.

Pick a color by **what it means**, not by how it looks.

## How to use in an app

```tsx
// Good: pick a token by meaning
<Button variant="accent">Save</Button>
<div className="bg-card text-card-foreground border-2 border-border">...</div>

// Bad: hard-coded colors bypass the theme
<div className="bg-[#06d6a0]">...</div>
```

To change a color everywhere, edit the variable in `src/styles.css` once.
